# LLM 学习路线

> **注意：** 本文档同时存在于项目根目录（`LLM学习路线.md`）和在线文档目录（`docs/学习路线.md`）中，两者内容保持一致。根目录版本方便 GitHub 浏览，docs 版本用于在线文档站点。

## 学习路线概述

本学习路线基于 [LLM Universe](https://github.com/datawhalechina/llm-universe) 项目设计，旨在帮助初学者系统化地学习大语言模型（LLM）应用开发。整个学习路线分为三个阶段，从基础入门到进阶技巧，再到实战应用，循序渐进地掌握 LLM 开发的核心技能。

**适用人群：** 具备基础 Python 能力，对 LLM 应用开发感兴趣的开发者。不需要人工智能或算法基础。

**学习时长：** 第一阶段约 20-30 小时，第二阶段约 15-20 小时，第三阶段约 10-15 小时。

---

## 🎯 学习目标

完成本学习路线后，你将能够：

1. ✅ 理解大语言模型的基本原理和特点
2. ✅ 熟练调用各种主流 LLM API（GPT、文心一言、讯飞星火、智谱 GLM 等）
3. ✅ 掌握 Prompt Engineering 技巧
4. ✅ 搭建向量知识库和 RAG（检索增强生成）应用
5. ✅ 使用 LangChain 构建复杂的 LLM 应用
6. ✅ 评估和优化 LLM 应用性能
7. ✅ 部署实用的 LLM 应用

## 🎓 学习建议

### 学习方法

1. **动手实践为主**
   - 每学完一章立即动手实践
   - 不要只看不做，代码要自己敲一遍
   - 遇到问题先思考，再查资料

2. **循序渐进**
   - 严格按照学习路线顺序学习
   - 不要跳跃式学习
   - 第一阶段务必完成所有实践任务

3. **记录总结**
   - 记录学习笔记和遇到的问题
   - 总结每个章节的核心知识点
   - 分享学习心得（博客、社区等）

4. **项目驱动**
   - 以自己的项目为目标
   - 边学边做，学以致用
   - 完成一个完整的项目

### 时间安排建议

- **全职学习：** 2-3 周完成第一阶段，1-2 周完成第二阶段
- **兼职学习：** 1-2 个月完成第一阶段，1 个月完成第二阶段
- **每日学习：** 建议每天投入 2-4 小时

### 环境准备

1. **硬件要求**
   - 不需要 GPU
   - 普通笔记本或云服务器即可
   - 至少 8GB 内存

2. **软件要求**
   - Python 3.8+
   - Jupyter Notebook 或 VS Code
   - Git

3. **API 准备**
   - 至少注册一个 LLM API（推荐智谱 AI 或文心一言）
   - 准备一些测试额度
   - 推荐同时注册多个以便对比

## ❓ 常见问题 FAQ

### Q1: 零基础可以学习吗？
A: 需要具备基础的 Python 编程能力。如果完全零基础，建议先学习 Python 基础（1-2 周）。

### Q2: 需要购买 GPU 吗？
A: 不需要。本教程使用 API 调用方式，普通电脑即可。

### Q3: API 费用大概多少？
A: 学习阶段，每个月几十元即可。建议同时注册多个平台获取免费额度。

### Q4: 学完后能找到工作吗？
A: 本教程是入门级，可以胜任初级 LLM 应用开发岗位。要找工作还需要：
- 深入学习相关理论
- 积累项目经验
- 了解企业实际需求

### Q5: 第二、三部分什么时候完成？
A: 第二、三部分正在创作中，建议先完成第一部分，持续关注项目更新。

### Q6: 遇到问题怎么办？
A: 
- 先查看项目的 [Issue](https://github.com/datawhalechina/llm-universe/issues)
- 在 Datawhale 社区提问
- 提交新的 Issue
